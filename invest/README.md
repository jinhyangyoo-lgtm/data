# 투자수익관리 (고속 조회 버전)

기존 페이지는 그대로 두고, 「투자관리 DB」 시트를 **읽기 전용**으로 보여주는 새 웹앱입니다.

## 배포 방법
1. script.google.com → 새 프로젝트 만들기 (「투자관리 DB」 시트에 연결된 프로젝트가 아니어도 됨. 시트 ID가 `Code.gs`에 들어 있음)
2. 파일 4개를 같은 이름으로 만들어 붙여넣기: `Code.gs`, `index.html`, `style.html`, `app.html`
3. 배포 → 새 배포 → 웹 앱 (실행: 나, 액세스: 본인만 또는 필요한 범위) → 처음 한 번 시트 접근 권한 승인
4. 입력·수정은 기존 페이지에서 계속 하고, 이 페이지는 조회용으로 사용

## 속도 개선 방식
- 4개 탭을 각각 1회만 읽음(필요한 열만) → 서버 캐시(5분, gzip)
- 브라우저에 마지막 데이터를 저장해 두었다가 접속 즉시 표시, 뒤에서 최신으로 갱신
- 외부 라이브러리 없음. 화면 상단 '새로고침'은 서버 캐시를 무시하고 시트에서 다시 읽음
